# Portfolio

My personal portfolio website v2, built from scratch. An improvement from the first version, 
applying lean web dev principles, focusing on lightweight, clean architecture, and zero unnecessary dependencies.

Check it out [here](https://mnvtagle-portfolio.vercel.app)!

## Pages

| Page | Description |
| --- | --- |
| Home | Bio, tools, and featured projects showcase |
| Credentials | Awards and course certifications |
| Projects | List of full-stack projects |
| About | Academic background, hobbies, and interests |
| Contact | Professional links, services offered, and internship availability |

## Tech Stack

| Component | Stack |
| --- | --- |
| Frontend | React (Vite, TypeScript) |
| Styling | Tailwind 4 w/ `cn` |
| Routing | React Router |
| State | Zustand |
| Hosting | Vercel |
